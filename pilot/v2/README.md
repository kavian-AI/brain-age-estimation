# Atlas v2

Second version of the healthy normative atlas: same 7,603-person pool and FastSurfer pipeline as `pilot/p5_out`,
with the model changes below, each kept only because a test on this pool showed it was needed.
The fitted atlas, a standalone scorer and the full validation are in [`atlas_v2/`](atlas_v2/README_atlas_v2.md).

| change vs `p5_out` | from | evidence (file) |
|---|---|---|
| male–female gap allowed to change with age (smooth), every structure | own check | `tissue_lr_tests.csv`, `csf_lr_tests.csv` |
| head-size exponent changing with age: temporal horn, 3rd ventricle | own check | `csf_lr_tests.csv` |
| head size in the spread: 3 CSF spaces | own check | `v2_spec_summary.csv` |
| scanner offsets shrunk toward the typical scanner (empirical Bayes) | BrainChart | `v2_spec_summary.csv` |
| left/right models for every paired structure | PCN braincharts | `pcn/`, `v2_final_paired.csv` |
| + caudate, pallidum, accumbens, ventral DC, cerebellar WM, 4th ventricle | PCN braincharts | — |

## Run order (from the repo root, `pip install -r requirements.txt`)

| step | command | time (4 CPU) | output |
|---|---|---|---|
| 1 | `python pilot/v2/published_heldout.py` | ~10 min | `published_heldout_z.csv.gz`, `published_calibration_by_*.csv` |
| 2 | `python pilot/v2/csf_variants.py`, `python pilot/v2/tissue_sexage.py` | ~12 + 10 min | `csf_lr_tests.csv`, `tissue_lr_tests.csv` |
| 3 | `python pilot/v2/orient_check.py` | 1 min | left/right orientation and QC-leakage pre-flight (printed) |
| 4 | `python pilot/v2/v2_spec_test.py` | ~16 min | `v2_spec_lr.csv`, `v2_spec_summary.csv` |
| 5 | `python pilot/v2/v2_build.py all` | ~23 min | `v2_calibration.csv`, `v2_transfer.csv`, OASIS scores, `atlas_v2/` tables |
| 6 | `python pilot/v2/v2_portable.py` | ~3 min | `atlas_v2/grid_v2.csv.gz`, `coefs_v2.csv`, `sites_v2.csv`, `portable_check.csv` |
| 7 | PCN comparison, see [`pcn/README.md`](pcn/README.md), then `python pilot/v2/v2_compare.py` | — | `v2_final_auc.csv`, `v2_final_paired.csv` |
| 8 | `python pilot/v2/neural_shash.py`, `audit.py`, `audit_power.py` | ~6 + 10 min | `neural_shash_results.csv`, audit tables |

The final model specification is `v2_config.json`; the model class is `atlas_v2_model.py` (extends `pilot/shash.py`).
`SMOKE=1 V2_OUT=pilot/v2/smoke python pilot/v2/v2_build.py all` runs every stage on 6 structures in ~1 minute.

Person-level tables (OASIS subject IDs with z-scores) and large intermediate held-out files are written here but
git-ignored, because the repository is public; they are regenerated by the steps above.
